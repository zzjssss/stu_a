第五题：异常处理（实用技能）
--------------------------------------------------------
编写一个函数 safe_divide(a, b)，实现安全的除法运算：
  - 正常情况返回 a / b 的结果（保留两位小数）
  - 当 b 为 0 时，捕获 ZeroDivisionError，返回 "错误：除数不能为零"
  - 当 a 或 b 不是数字时，捕获 TypeError，返回 "错误：参数必须是数字"
  - 使用 except Exception as e 兜底，返回 f"未知错误：{e}"

测试用例：
  print(safe_divide(10, 3))      → 3.33
  print(safe_divide(10, 0))      → 错误：除数不能为零
  print(safe_divide("a", 5))     → 错误：参数必须是数字
  print(safe_divide(10, []))     → 错误：参数必须是数字

第八题：挑战题 — 快速幂算法
--------------------------------------------------------
实现快速幂函数 fast_pow(base, exp)，计算 base 的 exp 次方。
要求：
  - 不能使用 ** 运算符和 math.pow
  - 使用分治思想：
      当 exp 为偶数：base^exp = (base^(exp/2))^2
      当 exp 为奇数：base^exp = base * base^(exp-1)
  - 支持 exp = 0 的情况（返回 1）
  - 使用递归或迭代均可

注意：之前练习中曾出现过 power%2 误写为 base%2 的 bug，
      请注意判断条件是对 exp 取模，不是对 base！

测试用例：
  fast_pow(2, 10)  → 1024
  fast_pow(3, 5)   → 243
  fast_pow(7, 0)   → 1
  fast_pow(2, 20)  → 1048576
